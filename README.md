# asc-to-heaven
 A funny little cultivation game for Terra!

This game is inspired by an unnamed vibe-coded AI game that I saw and decided that even I could make something better.

I didn't make something "better" per se, but I did end up making something that I... half enjoyed? it's a mess, but it was still nonetheless literally better than what I thought I would be able to make.

The most difficult part was honestly just navigating the sea of HTML and CSS that made me want to claw my eyes out. The actual game logic is not difficult, and you can simply go the browser game route of chucking everything into a `game` object. The assets also took a fair bit of time, but as the previous game had AI art, I decided that no matter what I wasn't going to use online assets. So I drew my own things.

The game loop is simple, but I wanted to add a bunch more at the time at the start of making this. E.g. 
- Essence has no use. (This is supposed to be Zhen Yuan, or mana equivalent, but I did not get around to adding spells)
- I wanted to add forging and equipment, using hides and whatnot to make stuff
- I wanted to add more tiers than just the base tier pills
- And I wanted to actually draw the backgrounds of the tabs instead of leaving most of them irritatingly blank with arbitrary buttons positions with no real meaning as to why they are there.
However, frankly, I got really bad burnout like halfway through. I just genuinely did not enjoy making the game. The game probably did not enjoy me making it either. 

Moving forwards I feel like I will stick more towards tools or mathy projects than games. My mentality is sort of just not suited for making games in my reflection.

# How to Play
Load `https://makerofdopamine.github.io/asc-to-heaven` in your browser. No installation is needed.

# AI use

AI was not used to write any major code. AI was used in assistance of one or two debugging steps for css and for explaining the tag `cubic-bezier`, and AI was used to build the dynamic shrinking system of the notifications that I ultimately abandoned in favor of my own simpler system of it shrinking towards the right.
